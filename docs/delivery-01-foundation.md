## Decisions

| Decision                            | Rationale                                                                  |
| ----------------------------------- | -------------------------------------------------------------------------- |
| Next.js 16                          | The latest version with a stable App Router                                |
| Tailwind v4                         | Generated by create-next-app; native CSS variables, no tailwind.config.js  |
| shadcn/ui 4.x                       | Native Tailwind v4 support; accessible components via Radix UI             |
| npm                                 | The only package manager tool available in the environment                 |
| Separate `uber-prep-next` folder    | Doesn't touch the legacy project while the migration progresses            |
| `suppressHydrationWarning` on html  | Needed for next-themes to avoid a hydration error                          |

---

## Risks

- **Tailwind v4 + shadcn/ui**: still in early adoption. Watch for breaking changes in future deliveries.
- **Next.js 16**: a very recent version. There may be incompatibilities with libs that assume Next 13/14/15.
- **Playwright + build**: the E2E tests run after `npm run build && npm start`. In CI, ensure port 3000 is free.
